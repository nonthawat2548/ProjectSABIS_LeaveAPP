# ปรับแต่งหน้าตา Leave

แนวทางของเวอร์ชันนี้คือพื้นที่ทำงานที่ดูอบอุ่น ใช้สีเขียวเข้มเป็นจุดยึด และสีมิ้นต์/ม่วง/พีช/ฟ้าเพื่อช่วยแยกประเภทข้อมูล การ์ดสรุปและปุ่มหลักจัดลำดับความสำคัญตามบทบาท ทุกจำนวนบน Dashboard อ่านจากข้อมูลจำลองที่ใช้งานอยู่

## แก้สีและรูปแบบ

เปิด `src/styles.css` ส่วน `:root` คือธีมสว่าง และ `:root[data-theme='dark']` คือธีมมืด เปลี่ยนตัวแปรเหล่านี้เพื่อปรับทุกหน้า:

| ตัวแปร | ใช้กับ |
| --- | --- |
| `--bg`, `--surface`, `--surface-soft` | พื้นหลังและการ์ด |
| `--ink`, `--muted`, `--subtle` | ข้อความหลักและคำอธิบาย |
| `--primary`, `--primary-hover`, `--on-primary` | ปุ่มและลิงก์หลัก |
| `--sidebar`, `--sidebar-muted` | เมนูด้านข้าง |
| `--hero`, `--hero-ink`, `--hero-muted` | ส่วนต้อนรับและหน้า Login |
| `--mint`, `--purple`, `--peach`, `--sky` | กลุ่มสีสถานะและข้อมูลสรุป |
| `--border`, `--shadow` | เส้นขอบและความลึกของการ์ด |

ตรวจสีข้อความกับสีพื้นหลังเมื่อเปลี่ยนธีม รวมถึงกรณีปุ่ม hover, ช่องกรอก, badge และข้อความรอง อย่าใช้สีเป็นตัวบอกสถานะเพียงอย่างเดียว; คงชื่อสถานะไว้ด้วย

ขนาดหน้าจอที่มี layout เฉพาะอยู่ใน media queries ท้ายไฟล์ ตารางกว้างและปฏิทินสามารถเลื่อนแนวนอนในกรอบของตัวเองได้บนจอเล็ก

## ฟอนต์และภาพประกอบ

ฟอนต์ **IBM Plex Sans Thai** จากแพ็กเกจ `@ibm/plex-sans-thai@1.1.0` อยู่ใน `public/fonts/` เป็น WOFF2 น้ำหนัก 400/500/600/700 พร้อมไฟล์ใบอนุญาต `OFL.txt` เก็บใบอนุญาตนี้ไว้เมื่อแจกจ่ายโปรเจกต์ ถ้าจะเปลี่ยนฟอนต์ให้แก้ `@font-face` และ `font-family` ใน CSS รวมถึง preload ใน `index.html`

ภาพปฏิทินและต้นไม้ `public/art/leave-garden.svg` และโลโก้ใน `src/ui.tsx` เป็น vector ที่สร้างสำหรับแอปนี้ แก้สีหรือรูปทรงใน VS Code ได้โดยตรง ไม่มีภาพบุคคลหรือภาพจากเว็บอื่นในแอป

## แก้หน้าจอ

- `src/App.tsx`: หน้า Login, แถบเมนู, header, การสลับธีม และปุ่มค้นหา
- `src/Dashboard.tsx`: การ์ดสรุปและ layout หน้าหลัก
- `src/ui.tsx`: hero, โควตา, ทีม, สัปดาห์ถัดไป, คำขอถัดไป และ dialog ค้นหา
- `src/pages.tsx`: แบบฟอร์ม รายละเอียดคำขอ ปฏิทิน สถานะงาน และหน้าจอ HR
- `src/components.tsx`: ตาราง สถานะ ปฏิทินเลือกวันที่ และ dialog ร่วม

ระบบจำธีมด้วยคีย์ `leave-ui-theme` ใน localStorage แต่ยังใช้งานการสลับธีมได้เมื่อเบราว์เซอร์ไม่อนุญาตให้เก็บค่านี้ การค้นหาใช้ snapshot ที่ repository กรองสิทธิ์ตามบัญชีแล้ว และลิงก์ไปยังหน้าจอที่ตรวจสิทธิ์ซ้ำ

วันที่แสดงผลยังต้องผ่าน `src/domain/date.ts`: **วัน/เดือน/ปี พ.ศ.** เช่น `5/12/2569` ส่วน API/ฐานข้อมูลเก็บ ISO ค.ศ. `2026-12-05` ห้ามบวก 543 กับวันที่ที่เก็บในฐานข้อมูล

## แหล่งอ้างอิงที่ใช้ศึกษา

- [Atlassian Design: Elevation](https://atlassian.design/foundations/elevation/) — การแยกชั้นพื้นผิวและเลือกใช้ขอบ/เงาอย่างมีจุดประสงค์
- [Atlassian Design: Color](https://atlassian.design/foundations/color/) — การกำหนดบทบาทของสีในระบบ UI
- [Linear: Features](https://linear.app/features) — ศึกษาการจัดลำดับข้อมูลและการเข้าถึงงานที่ต้องทำ
- [IBM Plex](https://github.com/IBM/plex) และ [ภาษาที่รองรับ](https://www.ibm.com/plex/languages/) — แหล่งฟอนต์และใบอนุญาตต้นฉบับ

ใช้แหล่งเหล่านี้เป็นแนวทาง ไม่ได้นำภาพหน้าจอหรือโค้ด UI ของผลิตภัณฑ์อื่นมาใช้

## ขอบเขตการตรวจสอบ

ตรวจ TypeScript, production build, สีข้อความหลัก/รองของทั้งสองธีม, server rendering ของหน้าจอ, กฎการลา และ API จำลองแล้ว การตรวจหน้าตาและคลิกใช้งานด้วยเบราว์เซอร์จริงยังไม่ได้ทำในรอบนี้ เนื่องจากเครื่องมือ preview ของโปรเจกต์ไม่พร้อม จึงควรเปิด `npm run dev` เพื่อตรวจบนอุปกรณ์เป้าหมายหลังแก้ layout ต่อ
