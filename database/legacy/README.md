# ตัวอย่างชุดเก่า

เก็บ `mock-db.json`, `mock.sqlite` และ `seed.sql` เดิมไว้เพื่ออ้างอิง แอปปัจจุบันเริ่มต้นด้วยชุด 10 คนใน `src/data/leave-management-10-people.json` และไม่อ่านไฟล์ในโฟลเดอร์นี้

หากต้องการนำตัวอย่างเก่าเข้า SQLite ให้ใช้ `database/schema.sql` ก่อน แล้วจึงใช้ `seed.sql` กับฐานใหม่ที่ว่าง ไฟล์เหล่านี้ไม่ใช่ข้อมูลจาก Supabase หรือข้อมูลที่ผู้ใช้บันทึกในแอป
